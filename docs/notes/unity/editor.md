# Unity 编辑器与基本操作

这篇全是操作。看是记不住的,得在编辑器里按一遍。

先说一句:我用的 Layout 是 **2 by 3**,面板位置和你可能不一样,所以下面只讲每个面板**干嘛的**,不讲它在屏幕哪儿。

::: tip 布局随时能换
右上角 **Layout** 下拉框选就行。想跟我一样选 **2 by 3**,想恢复默认选 **Default**。

面板不小心拖没了也别慌,Layout 选一下回来,东西不会丢。
:::

## 一、这几个面板是干嘛的

| 面板 | 干嘛的 |
| --- | --- |
| **Hierarchy** | 当前场景里有哪些物体,一棵树 |
| **Scene** | 编辑用的 3D 视图。随便飞、随便拖 |
| **Game** | 相机实际看到的画面。**玩家看到的就是这个** |
| **Inspector** | 选中物体的所有属性,改数值就在这 |
| **Project** | 整个项目的文件(素材、脚本、场景) |
| **Console** | 日志和报错。**出问题第一个看这里** |

**Scene 和 Game 一定要分清。** Scene 是你编辑用的,Game 是玩家看到的。摆相机的时候眼睛得盯着 Game。

Console 建议一直开着。新手的问题九成都会在这报出来,`Ctrl` + `Shift` + `C` 直接开关。

## 二、怎么在场景里飞

最先要练熟的就是这个。全在 Scene 面板里操作。

| 操作 | 效果 |
| --- | --- |
| 按住**右键**拖 | 转视角 |
| 按住**中键**拖 | 平移 |
| **滚轮** | 拉近拉远 |

**飞行模式最常用**:按住右键不放,然后

| 按键 | 效果 |
| --- | --- |
| `W` `A` `S` `D` | 前后左右飞 |
| `Q` `E` | 下降 / 上升 |
| 加 `Shift` | 加速。场景大的时候很救命 |

松手就停。熟练之后基本一直在用这个。

另外还有 `Alt` 组合键,不用一直按着右键:

| 操作 | 效果 |
| --- | --- |
| `Alt` + 左键拖 | 绕着物体转 |
| `Alt` + 中键拖 | 平移 |
| `Alt` + 右键拖 | 推拉 |

### 找不到东西了就按 F

1. 在 Hierarchy 里点选物体
2. 鼠标移到 Scene 面板里
3. 按 **`F`**

视角立刻飞过去。或者在 Hierarchy 里**双击**物体名字,一样。

还有两个摆相机特别好用的:

| 快捷键 | 效果 |
| --- | --- |
| `Ctrl` + `Shift` + `F` | 把**选中物体**移到当前视角的位置 |
| `Ctrl` + `Alt` + `F` | 让**视角**对准选中物体 |

`Ctrl` + `Shift` + `F` 我常用:先把视角飞到想要的位置,选中相机,按一下,相机就位了。

## 三、移动、旋转、缩放

选中物体,身上会冒出彩色箭头,这叫 **Gizmo**。

### 六个工具,六个键

| 键 | 工具 | 长什么样 |
| --- | --- | --- |
| `Q` | 抓手 | 没手柄,就是平移视图 |
| `W` | **移动** | 三根箭头 |
| `E` | **旋转** | 三个圈 |
| `R` | **缩放** | 三个方块 |
| `T` | Rect Tool | 一个方框,做 UI 和 2D 用 |
| `Y` | 综合 | 移动旋转缩放一起显示 |

**`W` `E` `R` 这三个键你会按一辈子,现在就记住。**

不想记快捷键的话,工具按钮在 Scene 视图左上角那个浮层里(Unity 6 叫 Overlays)。

### 拖手柄的两个细节

拖箭头的**杆** → 沿一根轴走。
拖箭头尖端的**小方块** → 在一个平面上走。

旋转同理,圈是绕单轴,圈外面是自由转。

### 两个必须搞懂的切换

这俩按钮也在 Scene 左上角浮层里,搞混了会很难受。

**① Pivot / Center**

| | 什么意思 |
| --- | --- |
| **Pivot** | 以物体自己的轴心为基准 |
| **Center** | 以物体的几何中心为基准 |

选多个物体的时候差别最明显。

**② Local / Global**

| | 什么意思 |
| --- | --- |
| **Global**(地球) | 箭头永远指世界的 X/Y/Z |
| **Local**(方块) | 箭头跟着物体自己的朝向 |

方块转了 45° 之后:Global 的箭头还是横平竖直,Local 的跟着歪。**摆倾斜的东西必须切 Local**,不然你会对着箭头怀疑人生。

### 吸附

| 操作 | 效果 |
| --- | --- |
| 拖动时按住 `Ctrl` | 按固定增量吸(默认位置 1、旋转 15°) |
| 再加 `Shift` | 增量减半 |
| 拖动时按住 `V` | **顶点吸附**,把顶点吸到另一个顶点上 |

`V` 特别好玩,拼积木、搭关卡全靠它。吸附增量在 **Edit → Grid and Snap Settings** 里改。

## 四、选中和操作物体

| 操作 | 效果 |
| --- | --- |
| 点 Hierarchy 里的名字 | 选中 |
| `Ctrl` + 左键 | 加选 / 取消 |
| `Shift` + 左键 | 选连续一段 |
| 在 Scene 里拖框 | 框选 |
| `Ctrl` + `D` | 复制,复制品就在原地 |
| `Delete` | 删 |
| `F2` | 改名 |
| `Ctrl` + `Z` / `Ctrl` + `Y` | 撤销 / 重做 |

## 五、GameObject 和组件

这个是 Unity 最核心的概念,一定要绕清楚。

::: warning GameObject 本身什么都不会做
它就是个**空壳**。能动、能发光、能出声,全是因为身上挂了**组件**。
:::

### Transform

新建任何物体,Inspector 第一项永远是 **Transform**,而且**删不掉**。

| 字段 | 是什么 |
| --- | --- |
| **Position** | 位置 |
| **Rotation** | 旋转 |
| **Scale** | 缩放,`1` 是原始大小 |

**`1` 不是 `0`** —— 缩放归零的话物体就没了。想恢复原状用齿轮里的 Reset。

### 加组件

- Inspector 最下面 **Add Component**,搜名字
- 菜单 **Component** → 找分类
- 直接把脚本文件从 Project 拖到物体上

### 新建物体

| 方式 | 位置 |
| --- | --- |
| 菜单 | **GameObject → 3D Object → Cube / Sphere / Plane** |
| Hierarchy 空白处右键 | 菜单更短 |
| `Ctrl` + `Shift` + `N` | 新建**空物体**(只有一个 Transform) |

空物体很好用。它没外观,但能当文件夹整理场景,也能当父物体控制一堆东西。

## 六、Inspector 里几个没人告诉你的功能

| 功能 | 在哪 | 干嘛的 |
| --- | --- | --- |
| **Copy / Paste Component Values** | 组件右上角**齿轮** | 把一个组件的数值复制到别的物体上。**调参省一半时间** |
| **Reset** | 同一个齿轮菜单 | 恢复默认值 |
| **锁定** | Inspector 右上角**小锁** | 锁住后点别的物体这里不变,方便对照着改 |
| **Debug 模式** | 右上角**三个点** → Debug | **能看见私有字段** |

::: tip Debug 模式单独说一句
有些数值在 Inspector 里看不到,因为它是 `private`,或者没加 `[SerializeField]`。

切到 Debug 模式就能看。排查"这个值到底改没改"的时候特别有用。
:::

## 七、父子关系

**怎么建**:在 Hierarchy 里把子物体**拖到**父物体名字上放开(拖到名字上,不是旁边)。

建好之后:

- 移动父物体 → 子物体**跟着动**
- 旋转父物体 → 子物体**绕着转**
- 删父物体 → 子物体**一起没**

::: warning 这里有个坑
子物体的 Position 显示的是**相对父物体**的坐标。

你看到 Position 是 `(0, 0, 0)`,但物体明明在屏幕另一头 —— 因为它的父物体在那。
想确认世界坐标,看 Position 下面那行灰色小字。
:::

我一般在两种地方用:

- **一个角色** = 空物体当父(控制整体移动)+ 模型、武器、碰撞体当子
- **一辆车** = 父物体 + 四个轮子

## 八、预制体 Prefab

**Prefab = 能重复用的物体模板。**

场景里放了 50 个一模一样的敌人,改一个要改 50 遍?用 Prefab 改一次就行。

**创建**:把 Hierarchy 里的物体**拖到 Project 面板**里。名字会变成**蓝色**,这就是 Prefab。

**使用**:从 Project 拖回场景,就是一个**实例**。

**改**:

- **只改这一个** → 直接在场景里改
- **改所有的** → 双击 Project 里的 Prefab 进编辑模式(场景会变暗),改完点左上角 **←** 退出
- **把这次的改动推给所有实例** → Inspector 里 **Overrides** → **Apply All**
- **撤销这个实例的改动** → Overrides → **Revert All**

::: danger 这里是新手最困惑的地方
你在**场景里**改 Prefab 实例,**默认只影响这一个**。

想让所有实例都变,必须显式点 **Apply**。

"我明明改了,怎么别的没变?" —— 就是这个原因。
:::

## 九、运行、暂停、逐帧

Scene 面板正上方中间三个按钮:

| 按钮 | 快捷键 | 效果 |
| --- | --- | --- |
| ▶ | `Ctrl` + `P` | 运行 |
| ⏸ | `Ctrl` + `Shift` + `P` | 暂停 |
| ⏭ | `Ctrl` + `Alt` + `P` | 逐帧,按一下走一帧 |

运行时按钮会变蓝,提醒你在 Play 模式里。

::: danger Play 模式下改的东西,退出就全没了
这是我踩得最多的坑:

- 运行中在 Inspector 改的数值 → **退出后还原**
- 运行中拖动物体位置 → **还原**
- 运行中新建的物体 → **直接消失**

**想留下改动**:运行中对着组件**齿轮 → Copy Component**,退出 Play,再**齿轮 → Paste Component Values**。

还有个更阴的:**Play 模式下切场景,改动会真的保存。**
所以养成习惯 —— **进 Play 之前先 `Ctrl` + `S`。**
:::

## 十、保存和项目文件

| 快捷键 | 效果 |
| --- | --- |
| `Ctrl` + `S` | 保存当前**场景** |
| `Ctrl` + `Shift` + `S` | 另存为 |

::: warning `Ctrl` + `S` 只保存场景
Unity 是**边改边存**的。你在 Project 里建文件夹、改素材导入设置,这些立刻生效,不用保存。

**只有场景(Hierarchy 里的东西)要手动存。**
:::

项目目录里几个文件夹:

| 文件夹 | 是什么 |
| --- | --- |
| **`Assets/`** | **你的东西全在这**。素材、脚本、场景、Prefab |
| `ProjectSettings/` | 项目各项设置。也要进 Git |
| `Packages/` | 依赖包列表,`manifest.json` 要进 Git |
| `Library/` | Unity 生成的缓存。**巨大,可以随时删**,重开会重建 |

Git 的 `.gitignore` 大概这样:

```text
Library/
Temp/
Obj/
Build/
Builds/
Logs/
UserSettings/
*.csproj
*.sln
```

::: danger `.meta` 文件绝对不能忽略
每个资源都配一个 `.meta`,里面记着 GUID 和导入设置。

**丢一个,对应的引用就断一处**,场景里一堆 `Missing`。也**永远不要手动删**它们。
:::

## 十一、写第一个脚本

1. Project 面板里 `Assets` 下右键 → **Create → C# Script**,起名比如 `Hello`
2. 双击打开
3. 默认长这样:

```csharp
using UnityEngine;

public class Hello : MonoBehaviour
{
    void Start()
    {
        // 游戏开始时跑一次
        Debug.Log("Start 跑了");
    }

    void Update()
    {
        // 每一帧跑一次
    }
}
```

4. **把脚本从 Project 拖到 Hierarchy 的物体上**
5. `Ctrl` + `P` 运行,看 Console 有没有输出

::: danger 文件名必须和类名一模一样
类叫 `Hello`,文件就必须叫 `Hello.cs`。不一样的话 Unity 直接报错,挂不上去。

另外**别用中文、空格、横杠**,只用字母数字下划线。
:::

## 十三、我踩过的坑

**1. Play 模式下改的东西退出后全没了。**
第一高频的坑。进 Play 前先 `Ctrl` + `S`。

**2. 场景没保存就关 Unity。**
会弹对话框,但很容易手快点掉。养成 `Ctrl` + `S` 的肌肉记忆。

**3. 子物体的 Position 是相对坐标。**
看到 `(0,0,0)` 但物体不在原点,先看它有没有父物体。

**4. 改了 Prefab 实例,别的实例没变。**
默认就是这样,要同步得点 **Apply**。

**5. 脚本挂不上。**
看 Console 第一条红字。常见原因:文件名和类名不一致、少了大括号、`using` 没加。

**6. 把 `.meta` 删了或没提交。**
引用全断。永远不要手动删 `.meta`。

**7. 用中文命名脚本。**
能跑,但换平台或者上 Git 容易乱。**统一用英文。**

**8. 在 `MonoBehaviour` 上写构造函数。**
Unity 的物体不是 `new` 出来的,构造函数根本不会被调。初始化写 **`Awake()`** 或 **`Start()`**。

**9. 分不清 Scene 和 Game。**
摆相机的时候眼睛盯 Game,别盯 Scene。
