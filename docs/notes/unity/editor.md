# Unity 编辑器与基本操作

这一篇全是**操作**:按哪个键、点哪里、会发生什么。建议开着 Unity 对着按一遍。

::: tip 前提
新建一个 **3D (Built-in Render Pipeline)** 项目就行。下面的操作 2D 项目也基本一样,
只是场景里没有 Z 轴。
:::

## 一、先认识 6 个面板

打开 Unity,默认长这样,分 6 块:

| 面板 | 位置 | 干什么的 |
| --- | --- | --- |
| **Hierarchy** | 左上 | 列出**当前场景里**的所有物体(一棵树状列表) |
| **Scene** | 中间 | **编辑用**的 3D 视图,可以随便飞、随便拖 |
| **Game** | 中间(标签页) | **相机实际看到的画面**,就是玩家最终看到的东西 |
| **Inspector** | 右侧 | 显示**当前选中物体**的所有属性,也是你改数值的地方 |
| **Project** | 底部 | 列出**整个项目**的所有文件(素材、脚本、场景……) |
| **Console** | 底部(标签页) | 打印日志和报错,**出问题第一个看这里** |

### 面板不见了怎么办

**方法一**:右上角有个 **Layout** 下拉框 → 选 **Default**,一键恢复成默认布局。

**方法二**:上面菜单栏 **Window → General** 里找到对应面板点一下。

**方法三**:先把布局调乱也没关系,`Layout` → `Save Layout...` 可以存成自己的布局。

::: tip Console 一定要常开着
新手 90% 的问题(脚本没挂上、变量没赋值、空引用)都会在 Console 里报出来。
快捷键 `Ctrl` + `Shift` + `C` 可以直接打开/关闭 Console。
:::

## 二、场景视角:怎么在场景里"飞"

这是最先要练熟的。**全在 Scene 面板里操作。**

### 基础三种动作

| 操作 | 效果 |
| --- | --- |
| **按住鼠标右键拖动** | 转动视角(像转头看四周) |
| **按住鼠标中键拖动** | 平移视角(像整个人左右上下移) |
| **滚轮前后滚** | 拉近 / 拉远 |

### 飞行模式(最常用)

**按住右键不放**,然后:

| 按键 | 效果 |
| --- | --- |
| `W` / `A` / `S` / `D` | 前后左右飞 |
| `Q` / `E` | 下降 / 上升 |
| 同时按住 `Shift` | 加速飞(场景大的时候很救命) |

松手就停。熟练之后你会一直在用这个。

### Alt 组合键(不用按住右键)

| 操作 | 效果 |
| --- | --- |
| `Alt` + 左键拖动 | 绕着选中物体转 |
| `Alt` + 中键拖动 | 平移 |
| `Alt` + 右键拖动 | 推拉(缩放) |
| 滚轮 | 以当前轴心为中心缩放 |

### 聚焦到某个物体(高频)

1. 在 **Hierarchy** 里点选一个物体
2. 把鼠标移到 **Scene** 面板里
3. 按 **`F`**

视角会立刻飞到那个物体上。**找不到东西了就按 F。**
或者直接在 Hierarchy 里**双击**物体名字,效果一样。

### 另外一个很有用的

| 快捷键 | 效果 |
| --- | --- |
| `Ctrl` + `Shift` + `F` | **Align With View** —— 把选中物体移到当前视角的位置 |
| `Ctrl` + `Alt` + `F` | **Align View to Selected** —— 让视角对准选中物体 |

摆相机的时候 `Ctrl` + `Shift` + `F` 特别好用:先把视角飞到想要的位置,选中相机,按一下,相机就位了。

## 三、移动 / 旋转 / 缩放手柄(Gizmo)

选中一个物体,它身上会出现**彩色箭头**。这些箭头叫 **Gizmo(手柄)**。

### 六个工具,六个键

| 快捷键 | 工具 | 手柄长什么样 |
| --- | --- | --- |
| `Q` | Hand(抓手) | 没有手柄,就是平移视图 |
| `W` | **Move(移动)** | 三根箭头 |
| `E` | **Rotate(旋转)** | 三个圆圈 |
| `R` | **Scale(缩放)** | 三个方块 + 中心方块 |
| `T` | Rect Tool | 一个方框,做 UI、2D 用 |
| `Y` | Transform 综合 | 移动 + 旋转 + 缩放同时显示 |

**`W` `E` `R` 这三个键你会按一辈子,现在记住。**

工具按钮本身在 **Scene 视图左上角那个浮层**里(Unity 6 叫 Overlays),不想记快捷键就点那里。

### 拖手柄的两个细节

**拖箭头中间的线** → 沿单一轴移动。
**拖箭头尖端的小方块** → 沿两个轴组成的平面移动。

旋转同理,圆圈是绕单轴,圆圈外围是自由旋转。

### 两个容易搞混的切换按钮

这两个按钮都在 Scene 视图左上角浮层里,**一定要搞清楚**:

**① Pivot / Center(轴心 vs 中心)**

| | 含义 |
| --- | --- |
| **Pivot** | 以物体自己的**轴心点**为基准(空物体的轴心就在原点) |
| **Center** | 以选中物体的**几何中心**为基准 |

多个物体一起选中的时候差别很明显。

**② Local / Global(局部 vs 世界坐标)**

| | 含义 |
| --- | --- |
| **Global**(地球图标) | 箭头永远指向世界的 X / Y / Z 方向 |
| **Local**(立方体图标) | 箭头跟随物体自己的朝向 |

一个方块被旋转了 45° 之后,`Global` 模式的箭头还是横平竖直,`Local` 模式的箭头跟着歪。**摆倾斜的东西必须切 Local。**

### 吸附(对齐神器)

| 操作 | 效果 |
| --- | --- |
| 拖动时**按住 `Ctrl`** | 按固定增量吸附(默认位置 1 个单位、旋转 15°) |
| 拖动时**按住 `Ctrl` + `Shift`** | 吸附增量减半 |
| 拖动时**按住 `V`** | **顶点吸附** —— 把物体的顶点吸到另一个物体的顶点上 |

`V` 顶点吸附是拼积木、做关卡的时候最常用的一个技巧。

::: tip 吸附增量在哪改
菜单 **Edit → Grid and Snap Settings...** 里可以改位置吸附和旋转吸附的步长。
:::

## 五、GameObject 和「组件」

这是 Unity 最核心的概念,务必弄清楚:

::: warning GameObject 本身**什么都不会做**
一个 GameObject **只是一个空壳容器**。它之所以能动、能发光、能响,

完全是因为**挂在它身上的组件(Component)**。
:::

### Transform 是唯一每个物体都有的组件

新建任何物体,Inspector 里第一项永远是 **Transform**,而且是**删不掉**的。

| 字段 | 含义 |
| --- | --- |
| **Position** | 位置 |
| **Rotation** | 旋转(Inspector 里显示的是欧拉角,脚本里是四元数) |
| **Scale** | 缩放,`1` 是原始大小 |

Transform 右上角**齿轮图标 → Reset**,可以把 Position/Rotation/Scale 一次全部归零。

### 怎么加组件

**方法一**:Inspector 最下面 **Add Component** 按钮,搜组件名。

**方法二**:菜单 **Component** → 找分类。

**方法三**:直接把脚本文件从 Project 面板**拖到** Hierarchy 里的物体上。

### 新建物体

| 方式 | 位置 |
| --- | --- |
| 菜单 | **GameObject → 3D Object → Cube / Sphere / Plane / Cylinder ...** |
| Hierarchy 空白处**右键** | 同上,菜单更短 |
| 快捷键 `Ctrl` + `Shift` + `N` | 新建一个**空物体**(只带 Transform) |

**空物体非常有用**:它没有任何外观,但可以当**文件夹**用来整理场景,也可以当**父物体**用来控制一组东西。

## 六、Inspector 里几个救命功能

这些没人教但极其好用:

| 功能 | 在哪 | 有什么用 |
| --- | --- | --- |
| **Copy Component / Paste Component Values** | 组件名右上角**齿轮**图标 | 把一个组件的数值复制到另一个物体上,**调参时省大量时间** |
| **Reset** | 同上齿轮菜单 | 把这个组件恢复成默认值 |
| **锁定 Inspector** | Inspector 右上角**小锁图标** | 锁定后,点别的物体 Inspector 不变,方便**对照着改** |
| **Debug 模式** | Inspector 右上角**三个点** → Debug | **显示私有字段和隐藏属性**,找不到某个变量时切过来看 |

::: tip Debug 模式值得单独记一下
有时候你在 Inspector 里**看不到**某个数值(因为它是 `private` 的,或者没加 `[SerializeField]`),
切到 Debug 模式就能看到。**排查"这个值到底有没有被改"时特别有用。**
:::

## 七、父子关系

### 怎么建立

在 **Hierarchy** 里,把子物体**拖到**父物体身上放开(拖到名字上,不是拖到旁边)就建立了父子关系。

也可以在脚本里用 `transform.SetParent(...)`。

### 父子关系意味着什么

**子物体的 Transform 变成相对父物体的。**

- 移动父物体 → 所有子物体**跟着动**
- 旋转父物体 → 所有子物体**绕着父物体转**
- 删除父物体 → 子物体**一起被删**

::: warning 这是把双刃剑
子物体的 Position 显示的是**相对父物体的坐标**,不是世界坐标。

你看到 Position 是 `(0, 0, 0)` 但物体明明在屏幕另一头,就是因为它的父物体在那儿。
想确认世界坐标就看 Inspector 里 Position 下面那行灰色小字,或者在 Debug 模式里看 `position`。
:::

典型用法:

- **一个角色** = 父物体(空物体,控制整体移动)+ 子物体(身体模型、武器、碰撞体)
- **一辆车** = 父物体 + 四个轮子做子物体

## 八、预制体(Prefab)

**Prefab = 可以重复使用的物体模板。**

场景里放了 50 个一模一样的敌人?改一个要改 50 遍?用 Prefab 就改一次。

### 创建

把 Hierarchy 里的物体**拖到 Project 面板**里。拖进去之后它的名字变成**蓝色** —— 这就是 Prefab。

### 使用

从 Project 面板把 Prefab 拖回场景,就生成了一个**实例(Instance)**。

### 修改

- **只改这一个**:直接在场景里改。Inspector 里会多出 **Overrides** 一栏,列出你改动了哪些属性
- **改所有实例**:双击 Project 里的 Prefab 进入编辑模式(场景会变暗),改完点左上角 **←** 退出
- **把这次的改动应用给所有实例**:Inspector 里 **Overrides** → **Apply All**
- **撤销这个实例的改动**:Overrides → **Revert All**

::: danger Prefab 的改动规则一定要理清
默认情况下,你在**场景里**改 Prefab 实例,**只影响这一个**。

想让改动同步给所有实例,必须显式点 **Apply**。
这是新手最容易困惑的一点 —— "我明明改了,怎么别的没变?"
:::

## 九、播放 / 暂停 / 逐帧

Scene 面板正上方中间有三个按钮:

| 按钮 | 快捷键 | 效果 |
| --- | --- | --- |
| ▶ | `Ctrl` + `P` | **进入运行模式** |
| ⏸ | `Ctrl` + `Shift` + `P` | 暂停 |
| ⏭ | `Ctrl` + `Alt` + `P` | **逐帧**(按一下走一帧,调试动画和物理必用) |

运行时按钮会变成蓝色,提醒你**现在在 Play 模式里**。

::: danger Play 模式下改的东西,**退出时全部还原**
这是新手踩得最多的坑:

- 运行中在 Inspector 里改的数值 → **退出 Play 后回到原来的值**
- 运行中在 Scene 里拖动的物体位置 → **同样还原**
- 运行中新建的物体 → **直接消失**

**想保留改动怎么办?**
运行中改动 → 在 Inspector 里对着组件的**齿轮 → Copy Component** → 退出 Play → 齿轮 → **Paste Component Values**。

或者直接在 Hierarchy 里右键物体 → **Copy**,退出 Play 再 **Paste**。
:::

还有个更阴的坑:**Play 模式下切场景,改动会真的保存。** 所以养成习惯 —— **进 Play 之前先 `Ctrl` + `S` 保存场景。**

## 十、场景和项目文件

### 保存

| 快捷键 | 效果 |
| --- | --- |
| `Ctrl` + `S` | 保存当前**场景** |
| `Ctrl` + `Shift` + `S` | 另存为 |

::: warning `Ctrl` + `S` 保存的是场景,不是整个项目
Unity 是**边改边存**的:你在 Project 面板里新建文件夹、改素材导入设置,这些**立刻生效**,
不需要保存。**只有场景(Hierarchy 里的东西)需要手动保存。**
:::

### 项目目录里都有什么

| 文件夹 | 是什么 |
| --- | --- |
| **`Assets/`** | **你的东西全在这**。所有素材、脚本、场景、Prefab。**只有这个目录需要放进 Git** |
| `ProjectSettings/` | 项目的各项设置(输入、物理、图形……),**也要进 Git** |
| `Packages/` | 依赖的包列表,`manifest.json` 要进 Git |
| `Library/` | Unity 自己生成的缓存,**极大、可以随时删**(删了重开项目会重建) |

::: tip 用 Git 管 Unity 项目
`.gitignore` 里要忽略:

```text
Library/
Temp/
Obj/
Build/
Builds/
Logs/
UserSettings/
*.csproj
*.sln
```

`.meta` 文件**绝对不能忽略** —— 每个资源都配一个 `.meta`,它记录了资源的 GUID 和导入设置,丢了关联就全断了。
:::

## 十一、写下第一个脚本

1. 在 **Project** 面板里,`Assets` 下右键 → **Create → C# Script**,命名比如 `Hello`
2. 双击打开(用你配好的编辑器)
3. 默认内容长这样:

```csharp
using UnityEngine;

public class Hello : MonoBehaviour
{
    void Start()
    {
        // 游戏开始时执行一次
        Debug.Log("Start 跑了");
    }

    void Update()
    {
        // 每一帧执行一次
    }
}
```

4. **把脚本文件从 Project 面板拖到 Hierarchy 里的物体上**(或者选中物体,在 Inspector 点 Add Component 搜 `Hello`)
5. 按 `Ctrl` + `P` 运行,看 Console 里有没有输出

::: danger 文件名必须和类名一模一样
类叫 `Hello`,文件名就必须是 `Hello.cs`。改错了 Unity 会直接报错挂上不去。

另外:**脚本名字不要用中文、空格、横杠**,只用字母数字下划线。
:::

## 十三、常见坑

**1. Play 模式下改的东西退出后全没了。**
进 Play 前先 `Ctrl` + `S`。这是第一高频的坑。

**2. 场景没保存就关 Unity。**
Unity 会提示你,但对话框很容易手快点掉。养成 `Ctrl` + `S` 的肌肉记忆。

**3. 子物体的 Position 是相对坐标。**
看到 `(0,0,0)` 但物体不在原点,先看它有没有父物体。

**4. 改了 Prefab 实例,别的实例没变。**
默认就是这样。要同步必须点 **Apply**。

**5. 脚本挂不上 / 编译不过。**
看 Console 的第一条红字(后面的报错往往是连锁反应)。常见原因:文件名和类名不一致、少了右大括号、`using` 没加。

**6. 把 `.meta` 文件删了或没提交到 Git。**
所有引用会断掉,场景里一堆 `Missing`。**永远不要手动删 `.meta`。**

**7. 用中文命名脚本或资源。**
Unity 能跑,但换平台或上 Git 时容易出乱码问题。**统一用英文。**

**8. 在 `MonoBehaviour` 上写构造函数。**
Unity 的物体不是用 `new` 创建的,构造函数不会被调用。初始化写 **`Awake()`** 或 **`Start()`**。

**9. 分不清 Scene 和 Game 面板。**
**Scene 是你编辑用的,Game 是玩家看到的。** 摆相机的时候要盯着 Game 面板。
