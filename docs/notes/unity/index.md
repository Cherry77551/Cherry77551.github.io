# Unity 笔记

这套笔记接着 [C# 笔记](../dotnet/) 往下走 —— 那边学**语言**,这边学**引擎**。

## 用哪个版本

建议直接用 **Unity 6(版本号 `6000.x`)**,这是当前的 LTS。

- 下载用 **Unity Hub**,官网 `unity.com/download`,Hub 里可以同时装多个版本
- 装的时候至少要勾 **Windows Build Support**(或 Mac),不然发布了游戏
- **项目建好后不要随便升级版本。** 升级会重新导入所有资源(可能几十分钟),而且有些 API 会变,老代码直接编译不过

## 这套笔记怎么用

基本操作这类东西**看是记不住的**,得在编辑器里按。

建议做法:

1. 打开 Unity Hub,新建一个 **3D (Built-in Render Pipeline)** 项目,名字随便,比如 `Playground`
2. 对着下面每一条,在编辑器里按一遍
3. 按错了就 `Ctrl` + `Z`,或者关掉不保存
