## 想加新项目的话

照抄这个格式就行:

```md
## 项目名

**技术栈** · xxx / xxx
**状态** · 开发中 / 已完成 / 已归档

一两句话说清楚这东西是干嘛的、解决了什么问题。

[看详情](./项目文件名.md) · [源码](https://github.com/用户名/仓库名)
```

写完记得在 `docs/projects/` 下建个同名的 `.md` 文件,把细节写进去,然后在
[配置](https://github.com/Cherry77551/Cherry77551.github.io/blob/main/docs/.vitepress/config.mts)
的侧边栏里加一行。
